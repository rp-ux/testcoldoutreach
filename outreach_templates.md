## FRAMEWORK: Как персонализировать каждое сообщение

### Шаг 1: Определи pain point из аудита
| Тип компании | Типичные pain points |
|---|---|
| DeFi Protocol (Aave, Morpho, Uniswap) | Сложный onboarding, техничный контент не понятен институционалам, слабый YouTube |
| Infrastructure (Chainlink, Safe, Kiln) | B2B маркетинг слабый, нет case studies, developer marketing > end-user marketing |
| Hardware/Security (Ledger, Trezor) | Конкуренция с software wallets, trust issues после инцидентов, SEO war |
| Institutional (SG Forge, Mastercard, JPM) | Слабое Web3-native присутствие, не говорят на языке crypto community |
| L2/Scaling (Optimism, Arbitrum, Linea) | Ecosystem marketing, developer acquisition, community wars |

### Шаг 2: Выбери релевантную услугу
| Pain point | Услуга для pitch |
|---|---|
| Нет видео-контента | Video production: explainers, tutorials, founder interviews |
| Слабый LinkedIn | LinkedIn content strategy + ghostwriting для C-level |
| Нет PR-покрытия | PR campaign: tier-1 crypto media placement |
| Плохой SEO | Technical SEO + content cluster strategy |
| Community неактивное | Community management + engagement programs |
| Сайт непонятный | Website redesign / conversion optimization |
| Нет thought leadership | Content marketing: blog series, research reports, whitepapers |
| Конкуренты обходят в соцсетях | Social media management + paid promotion |

### Шаг 3: Добавь конкретику из аудита
Заменяй плейсхолдеры реальными данными:
- `{pain_point}` → "your YouTube hasn't been updated since Q3 2025"
- `{specific_gap}` → "Compound's blog gets 3x more organic traffic"  
- `{strength}` → "TVL growth from $8B to $25B this year"
- `{weakness}` → "zero LinkedIn posts from leadership in 6 months"
- `{metric}` → "organic search traffic" / "LinkedIn engagement" / "media mentions"

## ПРАВИЛА COLD OUTREACH

1. **Никогда не продавай в первом сообщении** — дай ценность (аудит, инсайт)
2. **Конкретика > общие фразы** — "ваш YouTube неактивен 6 мес" лучше "вам нужен контент"
3. **Один CTA на сообщение** — не давай выбор из 5 действий
4. **Максимум 3 follow-up** — после 3-го сообщения без ответа → стоп
5. **Персонализация обязательна** — имя + компания + 1 факт = минимум
6. **Timing**: отправляй Вт-Чт, 9-11 утра по timezone контакта
7. **LinkedIn**: connection request → follow-up через 24ч → reminder через 3д → final через 7д
8. **Twitter/X**: один DM, если нет ответа через 5 дней — не повторяй
